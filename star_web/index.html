SELECT TOP 10000
  p.objid, p.ra, p.dec, p.u, p.g, p.r, p.i, p.z,
  s.class, s.z AS redshift
FROM PhotoObj AS p
JOIN SpecObj AS s ON s.bestobjid = p.objid
WHERE s.scienceprimary = 1
ORDER BY p.objid
Fuente: SDSS SkyServer. La clase del catálogo se muestra después de predecir como referencia; no se envía al modelo. El scaler está incluido en el Pipeline.
